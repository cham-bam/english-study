# 🇺🇸 영어 단어 학습 프로젝트

## 프로젝트 개요
- **목표**: 5,000개 영어 단어 습득 (여행 + 비즈니스 중심)
- **방식**: 매일 10개 단어 학습 → 500일 완성
- **학습자 현재 수준**: 기초 완벽 + 중급 진입 단계 (약 1,500~2,000개 수준)

## 🔄 복습 주기 (망각곡선 기반)
- **1차 복습**: 학습 후 3일
- **2차 복습**: 학습 후 7일
- **3차 복습**: 학습 후 30일

---

## 🎯 학습 방식
1. **단어 학습** → 10개 단어 + 뜻 + 예문
2. **롤플레이** → 배운 단어 3개로 실제 대화 연습
3. **오답 기록** → 틀린 단어 자동 저장
4. **복습 알림** → 복습 Day 도래 시 자동 안내
