복습 확인 (5분)

2

신규 단어 학습 (20–30분)

"Day N 학습하자" → 단어 + 뜻 + 예문 + 발음 확인
각 단어 3회 소리 내어 읽기, 예문 1회 따라쓰기

3

자가 테스트 (5분)

틀린 단어 → 즉시 오답노트에 기록

4

롤플레이 / 예문 연습 (5–10분)

배운 단어 중 2–3개 선택 → 실제 상황 대화 or 예문 작성

5

진도 업데이트

"진도 업데이트해줘" → 진도관리.json + 오답노트.json 자동 저장
